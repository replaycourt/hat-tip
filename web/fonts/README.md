# Font

`source-serif-4-latin.woff2` is Source Serif 4 by Adobe, under the SIL Open Font License 1.1 (`OFL-source-serif-4.md`, copied from the font's repository). Source: `SourceSerif4Variable-Roman.ttf.woff2` from the release `4.005R` of https://github.com/adobe-fonts/source-serif (asset `source-serif-4.005_WOFF2.zip`).

Made with fontTools 4.57: subset to Basic Latin, Latin-1 and the punctuation the page uses (dashes, quotes, ellipsis, arrows, minus, no-break spaces), then the variable font instanced with the optical size fixed at 20 and the weight axis kept from 400 to 700. About 31 KB.
